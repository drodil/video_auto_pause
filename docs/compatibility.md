# Player compatibility

Video Auto Pause controls standard HTML video elements across sites. YouTube
also has player-specific active-ad detection and autoplay-next controls.

Streaming services such as Netflix, Twitch, Prime Video, Disney+, Vimeo,
Coursera, Udemy, Bilibili, X, TikTok, and Reddit are supported on a
best-effort basis. DRM, cross-origin frames, and custom players can limit
browser access to playback controls, so behavior may vary by site.

To report a site-specific problem, use **Report a site** in the settings. It
opens a GitHub issue draft containing the current site origin and browser; the
draft is not submitted automatically. Query strings and URL fragments are
excluded.
